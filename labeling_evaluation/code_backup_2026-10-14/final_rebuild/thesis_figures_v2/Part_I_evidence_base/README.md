## Source limits of the evtol.news inputs

- The evtol.news text used here (directory pages, development years, domain spec sheets) is the **public, non-member view**: 1 138 of the 1 229 crawled pages end with "VFS Member? Log in to read more!", so VFS-member-only content (probably more Resources entries) is missing. A year read from this text is an upper bound of when the aircraft first existed ("existed by" = a prototype existed by then, even if sub-scale), not a start date.
- Domain flag of the directory pages (rulings 2026-10-11): a power source offering an electric version counts as electric; only unmanned pages (cargo-only, no passengers, cargo drone) are UAVs; autonomous or remote pages count as piloted; hybrid-electric is not an electric option; an uncrewed demonstrator is out; the author's single-page rulings (review/domain_overrides.csv) override the rules. It applies to the evtol.news side only; the patent dataset's own domain gate is unchanged.

- External inputs (2026-10-11): the evtol.news development year, the TRL and the AAM Reality Index company map are set by rule-based scripts with no model (`viz/script_inputs.py`, lists in `review/script_outputs/`, written by notebook 60); where the author read an item in the review, his value is used. Agreement of each script with the author: notebook 60.

- Kinds of date used in the year review: **announced / unveiled** = presented as a project in order to start being developed (an already built aircraft shown is "existed by"); **existed by** = a prototype existed by then, even if sub-scale; a concept design has neither flown nor has a prototype.
